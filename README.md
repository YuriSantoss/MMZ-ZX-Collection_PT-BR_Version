# Mega Man Zero/ZX Collection PTBR Script

Este projeto é um **mod de tradução para o Portugues** para *Mega Man Zero/ZX Legacy Collection*,  
baseado na Tradução em espanhol (https://github.com/Vo1dTear/MMZC-Spanish-Script.git) do **Vo1dTear**.

Ele serviu totalmente como base, pois como sou iniciante não conseguiria fazer metade do que o Vo1dTear fez.

**Status do MOD**

- Mega Man Zero 1  | Totalmente traduzido
- Mega Man Zero 2  | Processo não iniciado



## Como Instalar

1. **Instale o MZZXLC Mod Loader**  
   Para utilizar o MOD é preciso baixar o **MZZXLC Mod Loader**(https://github.com/StraDaMa/MZZXLC-Mod-Loader/releases/latest).

2. **Localizar a pasta do jogo**  
   Na Steam, clique com o botão direito em *Mega Man Zero/ZX Legacy Collection* e vá em **Gerenciar → Explorar arquivos locais**.
   Isso ira abrir a pasta do jogo, se não houver uma pasta chamada `mods`, crie uma.

3. **Instale o mod**  
   Baixe a versão mais recente do MOD (LINK dos LASTEST), extraia o arquivo e coloque a pasta **MMZC-ZX-Collection_PT-BR_Version** dentro do seu diretório `mods`.

----
